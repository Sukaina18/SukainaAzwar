## GitHub Pages

This site is plain HTML with Tailwind CSS loaded from its CDN, so it can be hosted on GitHub Pages without a build step.

1. Create a GitHub repository and push this folder to its default branch.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The included workflow publishes the repository whenever changes are pushed to the default branch.

The contact links use email, phone, and LinkedIn. GitHub Pages does not run server-side form handlers; a form service or backend would be needed for a submission form.
